## ✨ About

**Scribble** is a modern and responsive landing page designed for discovering creative talent and exploring inspiring design work.

The website focuses on a clean visual experience with animated creator showcases, creative inspiration cards, and hiring-focused calls to action.

---

## 🚀 Features

- 🎨 Modern and minimal landing page
- 🖼️ Animated creative showcase
- ♾️ Infinite-style horizontal gallery
- 🎬 Autoplay creator videos
- ❤️ Interactive inspiration cards
- ✨ Hover animations and effects
- 📱 Responsive design for mobile and tablet
- 🎯 Hiring-focused call-to-action section
- 🔤 Custom typography using Google Fonts
- 🎭 Remix Icon integration

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
